## 本次整理对源码的修复

这些改动发生在开源整理阶段，不应写成 2025 年已经完成的课程成果。

1. 将显式声明的 `@vue/runtime-core` 对齐至 Vue 3.4.21，并更新锁文件。
2. 首页使用 uni-app `image` 组件，轮播素材改用英文文件名，避免本地 H5 资源路径无法正确读取。
3. 为微信胶囊按钮 API 添加平台条件，H5 使用普通顶部间距。
4. 调整分类侧栏固定宽度、商品区域收缩及购物车面板盒模型，改善窄屏显示。
5. 订单页将未安装的 `u-tabs` 替换为原生视图标签；修正空订单及详情返回的导航目标。
6. 修正定制商品数量增减时的金额、订单中的规格单价展示和“再来一单”的规格保留。
7. 移除失效的远程字体引用，地址空状态使用本地图标；将预置收货人改为“演示用户”。
8. 添加公开 README、运行截图、报告、MIT 许可范围及第三方素材说明，补充 GitHub Actions 构建流程。

本地的原始 Word 和程序 ZIP 未修改，也未放入 Git 提交。报告公开版只做个人标识脱敏与 PDF 导出，保留历史内容和原截图。
